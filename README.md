# yungas_pwa
Proyecto Yungas genero un PWA que es un proyecto/prototipo experimental pensado para senderistas y turistas para explorar cómo la tecnología libre, los mapas offline y las redes comunitarias pueden aportar a la seguridad de las yungas tucumanas.  Todo el sistema fue diseñado como una prueba de concepto abierta y gratuita. de codigo abierto
